# taiko-codex 首版实施方案

## 交付与范围

一次交付可在生产环境直接打开游玩的浏览器版本。玩法以两种击打为核心，用原创界面、谱面与程序合成音乐。使用中文界面和项目名 `taiko-codex`。

- 开场即可选两首示范曲，每首提供入门和进阶谱面。每局包括倒计时、判定、分数、连击、暂停、继续、重试和结算。
- `F/J` 击打鼓面，`D/K` 击打鼓边。触屏提供对应的左右手鼓垫。大音符允许单键完成，短时间双击加分。连打和气球单独计数。
- 设置包含音乐音量、击打音量、手动延迟和节拍校准。设备切换后可随时重新校准。
- 允许选择或拖入一份或多份 `.tja` 及相应的 `.ogg/.mp3/.wav/.m4a` 音频。根据 `WAVE` 匹配配对，以浏览器解码能力为准。UTF-8 与 Shift-JIS 谱面都能读取。曲包保存在本机 IndexedDB，可移除。
- 兼容常见 TJA 的普通、大音符、连打、气球、多难度、BPM、拍号、延迟、卷轴速度、分段加成、谱线开关。分支、双人谱及高级卷轴模式明确报错。对有兼容与不兼容难度的曲包，可导入可用的难度并显示警告。
- 首版范围截至 Web 试玩和本地导入。未来桌面封装、曲谱编辑器及 `.osu` 导入有明确的接入点。

## 技术与结构

使用 ES 模块、Canvas 2D、Web Audio 和 IndexedDB。所有运行时能力都由浏览器提供，音游主循环保持独立，静态产物可由 Nginx 或后续桌面 WebView 承载。构建与单测仅需要 Node.js 20+，发布时无需安装 npm 依赖。

| 模块 | 职责 |
| --- | --- |
| `src/tja.js` | 将 TJA 规范化为包含元数据、难度、音符、段落、拍线和时间范围的曲目对象 |
| `src/engine.js` | 不依赖浏览器，接受时间与击打数据，输出判定、连击、分数与结算 |
| `src/audio.js` | 解码音乐、播放击打音和校准节拍，把输入时间映射到音乐时间 |
| `src/library.js` | 内置清单、曲包导入与 IndexedDB，接入其他谱面格式时仍输出相同曲目对象 |
| `src/stage.js` | 缩放并绘制轨道，显示音符、拍线、连打和命中反馈 |
| `src/main.js` | 选曲、设置、游戏和结算界面，管理输入、暂停和资源生命周期 |
| `web/songs/` | 可扩展的内置曲库清单、原创 TJA 与音频 |

以 Web Audio 输出时间作为同一条音乐时间轴，按输入事件时间判定，暂停后重建音源并接续位置。校准使用固定节拍，基于有效击打的中位数给出偏移建议。音频先解码，再开始倒计时。素材目录作为本地参考保留，游戏以几何图形和合成声音自成完整视觉与声音体系。桌面版可以封装同一静态产物，并在曲库模块为本地目录增加读写入口。编辑器可复用规范化数据、谱面渲染与音频走带。

## 顺序与验收

1. 建立 dev 项目目录，写入发布规则及方案。
2. 一次完成示范曲制作、前端、引擎、导入、校准和静态部署脚本。
3. 使用 Node 测试时间轴、切拍、导入文件匹配和判定，在浏览器验收选曲、开局、暂停继续、完整结算、校准和导入，并检查小屏布局。
4. 将变更和每日记录推送至 OpenClaw dev 私仓。由 prod 桥接机建立同名私仓并同步首版。
5. 用 prod 提交启动独立容器，挂载专用 HTTPS 子域名。验证公网页面、曲谱、音频资源和实际试玩流程后交付链接。

格式参考：[TJAPlayer3 格式文档](https://iepiweidieng.github.io/TJAPlayer3/tja/)。
